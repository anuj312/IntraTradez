# Trend Hunter — Next Level Premium Theme

This build applies a full visual overhaul while preserving the scanner logic.

## What changed
- Rebuilt the dashboard aesthetic into a more cinematic terminal style.
- Redesigned sidebar, hero header, action pills and toolbar.
- Upgraded cards, shadows, glass surfaces and gradients.
- Converted leaderboard halves into more premium card containers.
- Upgraded row treatment, hover states and table headers.
- Enhanced Sector Flow into a richer dark presentation.
- Improved dark theme styling to match the redesign.

## Preserved behavior
- Main page still does not scroll.
- Top Gainers / Losers, Volume Ratio and % Change still show 6 rows initially.
- Internal table scroll still reveals rows 7–10.
- Sector Flow interactions are preserved.
- Scanner data bindings and backend logic are unchanged.
