# Trend Hunter / BLACK LABEL — Institutional Edition

A premium **presentation-only** update to the prior Signature Luxe build.

## Design language
- Refined metallic/silver-gradient Trend Hunter title and an integrated PRO tag
- Executive market status cluster with calibrated green live indicators
- Midnight-navy flagship dark theme, quiet hairlines, mint/violet accents
- Sharper controls, summary cards, and distinct long/short leaderboard surfaces
- Blueprint/grid Sector Flow chart treatment
- Matching light mode, accessibility contrast, and mobile typography

## Preserved
- Underlying scanner, API calls, scoring, sorting and session/login workflow
- `numbers.txt` authentication and Zerodha connectivity
- Full-screen desktop workspace with **no document scroll**
- Six stocks visible on standard desktop, scroll within panels to ten total
- Phone switching between Gainers and Losers, and one-screen Sector Flow bars

## Styling source
`black-label.css` contains the new additions. They are appended to
`premium-terminal.css`, which is embedded into `intraday-momentum-scanner.html`
for the existing Render deployment.
