# Trend Hunter / Obsidian Command Deck Sidebar

This visual-only update redesigns the existing left navigation panel with:

- A mint-gradient branded icon, intelligence desk microtype, refreshed logo text and a subtle dark constellation texture
- Four uniquely illustrated navigation cards, numbered modules, improved headings, tactile hover effects and richer active-state styling
- A glassy Research mode advisory card and compact Desk view profile
- Mobile retains the compact horizontal navigation, with all four views accessible by swiping the navigation strip

No Kite API, login, momentum calculations, 6-visible/10-total table limits, Sector Flow data, or backend logic were modified. The previous mobile fit-all Sector Flow bars setting is preserved.
